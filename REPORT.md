1. average
- правило: среднее с дробной частью.
- `average 10 20 31` → ждал 20.3333, было 20.
- причина: sum и length это int, по этому деление целое.
- фикс: `(double)sum / readings.Length`.
- граница: `average -100 100` даёт 0.

2. alarms
- правило: тревога если показание >= порога.
- `alarms 50 20 50` → ждал 1, было 0.
- причина: стояло `>`, поэтому равенство не считаеться.
- фикс: `reading >= threshold`.
- граница: `alarms -100 -100 -100 -100` даёт 3.

3. minimum
- правило: минимум среди всех показаний.
- `minimum 5 3 1` → ждал 1, было 3.
- причина: цикл шёл до `length - 1`, последний элемент не проверялся.
- фикс: `i < readings.Length`.
- граница: `minimum -100` даёт -100.

4. refuel
- правило: добавка прибавляется к запасу.
- `refuel 10 15` → ждал 25, было 15.
- причина: `Fuel = amount` затирал старый запас.
- фикс: `Fuel += amount`.
- граница: `refuel 100 0` даёт 100.

5. crew
- правило: name хранит переданное имя.
- `crew "Анна Вега"` → ждал Анна Вега, было UNKNOWN.
- причина: в конструкторе присваивался литерал.
- фикс: `Name = name`.
- граница: `crew "  Анна  Вега  "` пробелы сохраняются.

6. access
- правило: шлюз открыт только при двух верных факторах.
- `access 1 0` → ждал CLOSED, было OPEN.
- причина: стояло `||`.
- фикс: `&&`.
- граница: `access 0 0` даёт CLOSED.
